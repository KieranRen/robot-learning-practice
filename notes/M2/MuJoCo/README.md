# M2 - Robot Simulation with MuJoCo

## Overview

M2 focuses on robot simulation using MuJoCo.

The goal of this stage is to build a practical understanding of simulation environments, rigid bodies, geometry, contacts, joints, actuators, sensors, and basic robot control.

---

## Upstream Source

MuJoCo learning materials in M2 are based on:

https://github.com/Albusgive/mujoco_learning.git

The original repository belongs to its respective author(s).

My repository records my own notes, understanding, experiments, and progress based on this learning process.

## Topics

Current topics include:

- MuJoCo XML / MJCF structure
- Simulation configuration
- Visual settings
- Assets and materials
- Geometries
- Body hierarchy
- Sites
- Basic simulation practice

Future topics will include:

- Joints
- Actuators
- Sensors
- Kinematics
- Dynamics
- Control
